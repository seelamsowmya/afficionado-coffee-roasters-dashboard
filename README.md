# afficionado-coffee-roasters-dashboard

## Project Overview
This project analyzes product performance, revenue contribution, store performance, and hourly sales trends for Afficionado Coffee Roasters using Excel dashboards and pivot table analytics.

## Objectives
- Identify top-selling products
- Analyze category revenue contribution
- Compare store performance
- Analyze hourly revenue trends
- Identify top product types

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Dashboard Insights
- Coffee category generates highest revenue
- Hell's Kitchen is the top-performing store
- Peak sales occur during morning hours
- Brewed Chai Tea contributes significant revenue
